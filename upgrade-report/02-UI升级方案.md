# 02 · UI 升级方案

> 项目：Codex Remote Bridge（Chat 远程连接）v4.0.0
> 范围：Web 控制台 / Android Compose / Windows WPF / macOS SwiftUI 四端 UI 全面审计与低风险升级
> 日期：2026-08-04 ｜ 类型：审计 + 已实施优化 + 后续建议

## 一、各端 UI 现状审计结果

### 1. Web 控制台（public/index.html，9088 行 / ~397KB，单 style 块）

| 维度 | 现状 | 评价 |
|---|---|---|
| Token 化程度 | 原有 53 个 CSS 变量（颜色/布局/安全区/动效开关），本次新增 11 个颜色 token → 共 64 个 | 良好，颜色 token 覆盖率显著提升 |
| 硬编码颜色 | 审计前 **333 处**十六进制；已收敛 **97 处**为 var()；现状 **247 处**（净 -86，其余多为低频率专用色与 #fff 白） | 高频色已收敛，剩余多为一次性/低频率值 |
| 主题机制 | 双主题：`white-night`（浅色，:root 覆盖）+ `black-sky`（深色星尘背景，**默认启用**，localStorage 缺省即 black-sky）；另有 `dot-blue/dot-orange` 签名光效变体 | 设计巧妙但 token 作用域复杂，改动需校验两主题解析值 |
| 响应式 | 13 处 @media（≥900px 双栏、≤700px 移动、iPad 轨道等）+ 安全区/键盘 inset 变量 + 字体缩放 data 属性 | 优秀 |
| 可访问性 | 113 个 aria 属性；`aria-live` 5 处（notice/approval-queue/workspace/queued-send 等）；`:focus-visible` 焦点样式；`prefers-reduced-motion` 3 处 + `data-ui-motion=reduced`；icon-only 按钮均带 aria-label/title（静态与 JS 动态按钮均已核实） | 优秀，无需补漏 |
| 动效 | 统一微交互过渡已就位（button/a/[role=button] 等 20+ 选择器 150ms transition + hover opacity .92 + active scale .985，reduced-motion 下禁用）；签名光效/呼吸动画均在 prefers-reduced-motion 下关闭 | 良好 |
| 加载/空/错误态 | 有 `thread-option-spinner`（任务列表运行中，JS 注入 + aria-hidden）；消息 pending 仅文本级（`.message.pending .meta` 降透明度）；**无骨架屏** | 基本够用，可增强 |
| 滚动性能 | `html/body overflow:hidden` + `overscroll-behavior:none`；`will-change` 仅 2 处且用于动画元素；列表使用原生滚动容器 | 良好 |

### 3. Windows WPF（MainWindow.xaml）

- 已有 9 个 Brush 资源（Panel/Card/BorderSoft/Muted/Soft/Cyan/Green/Orange/Purple）+ 2 个按钮样式（LinkButton/ActionButton）。
- 全文件共 **47 处十六进制**：9 处为资源定义，**约 38 处内联硬编码**，且存在大量近似灰色（#77869A、#8090A4、#8493A8、#8796AA、#8F9EB2、#91A1B4、#8B9BB0、#738399、#8292A8…）。
- 评价：半 token 化 ——「系统级」已收敛，「组件级」仍散落；近似灰色有较大合并空间（中等风险）。

### 4. macOS SwiftUI（ContentView.swift）

- 无独立 token 体系，使用系统语义色（`.cyan/.green/.orange/.purple/.blue/.gray`）+ 白色透明度填充（0.30~0.58）+ 白 5.5% 面板填充/8% 描边。
- 背景渐变两色 `Color(red:0.06,green:0.07,blue:0.09)`≈#0F1217、`Color(red:0.10,green:0.11,blue:0.15)`≈#1A1C26，与 Android 色板（#101419 / #191F26）高度一致——主题一致性良好，但色值散落无命名。
- 评价：单文件小 UI，视觉一致；建议补一个 `Color` 扩展集中管理色板。

## 二、已实施的优化清单

### A. Web（public/index.html）

1. **高频色 token 化（零视觉变化）**：新增 11 个语义 token，替换 97 处硬编码色：
   - 暗色 chat 区：`--accent-blue #5eb4ff`（9 处）、`--accent-blue-soft #9ecbff`（5 处）、`--accent-amber #ffd68a`（4 处）、`--composer-bg #202020`（composer 背景 1 处）；
   - 浅色 workspace 区：`#111 → var(--accent)`（23 处）、`--text-strong #202020`（6 处）、`--ink #171717`（9 处）、`--muted-2 #8a8a8a`（9 处）、`--muted-3 #777`（8 处）、`--muted-4 #656565`（3 处）、`--hover-bg #f2f2f2`（6 处）、`--danger #b42318`（3 处）、`#f7f7f7 → var(--panel)`（4 处）、`#ededed → var(--panel-2)`（7 处）。
   - 校验原则：替换后每个 token 在 **black-sky 与 white-night 两主题下解析值与原十六进制完全一致**（black-sky 未覆盖的新 token 保持原值），实现零视觉变化、纯结构性收敛。刻意**未动** `#f1f1f1 → var(--user)`（black-sky 会改写 --user，属可见变化，列入后续项）。
2. **统一微交互过渡（此前已由用户加入，审计确认在位）**：20+ 选择器 150ms transition（background/border/color/shadow/opacity/transform），hover opacity .92、active scale(.985)，`prefers-reduced-motion` 与 `data-ui-motion=reduced` 下禁用。
3. **骨架屏/spinner 确认**：任务列表已有运行中 spinner（`.thread-option-spinner`，JS 注入并 `aria-hidden`）；消息加载为文本级 pending 态。**未新增骨架屏**（属中等风险视觉新增，列后续项）。
4. **aria-label 审计结论**：静态 HTML 与 JS 动态创建的按钮均具备可访问名称（文本内容 / aria-label / title），icon-only 按钮（drawer-close、attach、send、language-toggle 等）标签齐全，**无需补漏**。

### B. Android

1. `Color.kt`：新增 `val Success = Color(0xFF34A853)`（在线状态绿）。
2. `ConnectionScreen.kt`：`Color(0xFF34A853)` → 主题 token `Success`；移除不再使用的 `androidx.compose.ui.graphics.Color` 导入。
3. `BrowserScreen.kt`：`setBackgroundColor(0xFF101419.toInt())` → `setBackgroundColor(Background.toArgb())`（背景色与主题对齐，防 WebView 白闪）。

### C. 验证

- Web：`<style>` 花括号平衡；57 处 `var()` 引用全部有定义；内嵌 JS 通过 `node --check`；`node server.js` 实测 `GET /` 返回 200 且新 token 生效。
- Android：改动为纯替换 + 导入调整，语法自查通过（未跑 Gradle 构建，因依赖下载耗时，建议 CI 验证）。

## 三、建议的后续优化项与优先级

### Web（public/index.html）

| 优先级 | 优化项 | 内容 | 风险 |
|---|---|---|---|
| P1 | 消息骨架屏 | 首次进入/新会话加载时用 CSS 骨架占位（ shimmer 动画，reduced-motion 降级为静态）替代空白区 | 中 |
| P1 | `#f1f1f1` 收敛 | 将浅色区 7 处 `#f1f1f1` 收敛到新 token（不可复用 `--user`，black-sky 会改值；建议新增 `--hover-bg-soft`），并同步校验 black-sky 视觉 | 中 |
| P2 | 灰色阶收敛 | 低频率灰色 `#222/#333/#555/#666/#999/#dedede/#e5e5e5/#e6e6e6/#e8e8e8/#ececec/#f5f5f5/#bdbdbd/#cfcfcf` 等 30+ 处，先盘点再合并为「文本灰阶/描边灰阶」两组 token | 中（需逐色核对） |
| P2 | rgba alpha 变体 token 化 | `rgba(94,180,255,α)`(15 处)/`rgba(158,203,255,α)`(13 处)/`rgba(142,240,183,α)`(25 处)/`rgba(255,174,69,α)`(5 处) 建立 `--accent-blue-10/12/16/52/72` 等带透明度 token | 低 |
| P2 | 长列表滚动性能 | 线程/会话长列表加 `content-visibility:auto` + `contain-intrinsic-size`，降低渲染成本（注意与滚动锚定兼容性） | 中 |
| P2 | 抽屉焦点管理 | thread-menu/drawer 打开时焦点移入、关闭后归还，Esc 关闭；避免焦点逃逸到背景 | 中 |
| P3 | 字号/圆角/间距 token | 将散落字号（9~32px）、圆角（8~29px）、间距（3~32px）收敛为 `--fs-* / --radius-* / --space-*` | 中（量大） |
| P3 | 双主题对比度复检 | 以 WCAG AA（正文 ≥4.5:1）复核 white-night 下 `--muted/#6f6f6f`、`--faint/#969696` 与浅背景的对比度 | 低 |
